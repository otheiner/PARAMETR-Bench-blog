# PARAMETR-Bench

A simple standalone Jekyll Minima site for the PARAMETR-Bench project.

## Local preview

```bash
bundle install
bundle exec jekyll serve
```

Then open `http://localhost:4000`.

Alternatively, run the helper script:

```bash
./test_locally.sh
```

> On macOS, if `bundle install` fails while building native gems such as `bigdecimal`, install Xcode command line tools with:

```bash
xcode-select --install
```
